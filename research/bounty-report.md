## Notable Claims Requiring Cross-Reference

- **Official bounty-detail gap:** no sponsor-specific rubric, winner split, minimum number of API calls, requirement to deploy on mainnet, or credit-claim process is published on the Metropolis page. All “likely requires” statements above are informed recommendations, not official rules.
- **Agora vs PingBusiness:** primary page-card evidence maps both $10K bounties to Agora. The requested PingBusiness attribution and “up to $20,000 merchant rebate” were not corroborated in official Metropolis or Monad payment docs.
- **CVI/CVA ambiguity is resolved in favor of Cleanverse:** card branding is Cleanverse, and Cleanverse’s own site defines the initials. Crypto Volatility Index sources are irrelevant to this bounty.
- **MetaMask product ambiguity is resolved:** “Best Agent Wallet Plugin” matches the newly released Agent Wallet’s explicit plugin framework. Delegation Toolkit/ERC-7715 is distinct; a plugin might internally use smart accounts, but that is not what the title directly asks for.
- **Alchemy mainnet conflict:** current Alchemy product marketing implies mainnet/testnet coverage, but its Monad quickstart still says testnet only. Verify endpoint creation in the dashboard before selecting this bounty.
- **Aurora/NEAR chain-list conflict:** NEAR Intents docs list Monad, but Aurora Intents’ public icon list does not. Query supported tokens and execute a small end-to-end mainnet swap before committing.
- **Mera maturity:** Monad docs explicitly configure mainnet, but the GitHub library is still preview and warns that APIs may change before 1.0.
- **Cleanverse integration availability, CRE Monad deployment, Dynamic/Privy explicit Monad support, and Agora API access** all need sponsor confirmation; generic EVM compatibility alone does not guarantee bounty-eligible production access.
- **KIMI model drift:** the bounty only says KIMI; Moonshot’s current official page now highlights K3. Confirm whether credits are restricted to a model/project tenant.
- **No source used for a fast-moving product is older than 12 months.** Several living docs are undated; they are labeled with access date rather than publication date.
